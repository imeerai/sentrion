REFERENCE / RULES

Every block has a name.

When Sentrion stops something, it never shows a vague score — it names the exact rule that fired. This is the full default rule set: what each rule watches for, and whether it blocks, asks, or just warns.

Pre-flight

checked before any code runs
Rule

Default

Block
SCAN-02

Ask
SCAN-03

Block
SCAN-04
the name is one typo away from a popular package
Ask
REPO-01

Warn
REPO-02

Rule

Block

Block

Block

Block
Trust is narrow. Press Trust and Sentrion remembers that one package, that version range, and that exact behaviour. If a later version does something new, it asks again — which is what stops a hijacked update of a package you already rely on.
A live guard for the software you install and run. Open source, zero dependencies, no root.
